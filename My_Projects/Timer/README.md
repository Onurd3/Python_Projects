# ⏱️ Timer — Python

A simple and interactive **Countdown Timer** built using Python.  
The user enters a number of seconds, and the program counts down to zero while updating the screen in real time.

## 🚀 Features
- ⏲️ Countdown timer with live updates
- ⏸️ Auto-stop at zero
- 🔢 Accepts any number of seconds
- 🧼 Clean and readable code
- 🔄 Can be restarted easily

## 📦 Installation & Running
Make sure Python 3 is installed on your system.
