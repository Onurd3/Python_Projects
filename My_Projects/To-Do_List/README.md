# 📝 To-Do List — Python (Tkinter)

A simple and interactive **To-Do List application** built with Python and Tkinter.  
This program allows users to add, delete, and manage tasks through a clean graphical interface.

## 🚀 Features
- ➕ Add new tasks
- 🗑️ Delete selected tasks
- 🔄 Refresh task list automatically
- 💾 In-memory task storage
- 🪟 Simple and clean Tkinter GUI
- 🧼 Easy-to-read and beginner-friendly code

## 📦 Installation & Running
Make sure Python 3 is installed on your system.
