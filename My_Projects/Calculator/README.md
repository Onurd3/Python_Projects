# 🧮 Calculator — Python

A simple and interactive command-line **Calculator App** built using Python.  
This project supports the basic arithmetic operations and uses a clean, function-based structure that makes the code easy to understand and extend.

## 🚀 Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ❗ Handles invalid inputs & division by zero
- 🔁 Runs in a loop until the user chooses to exit
- 🧼 Simple and clean code structure

## 📦 Installation & Running
Make sure Python 3 is installed on your system.
