# 🎧 Underground Rap Studio Pro

A personal music library web application I developed to collect and listen to my own rap tracks, beats, and lyrics in one place.

🤖 **How It Was Built?**
This project was brought to life through my technical vision and pair programming with an AI assistant (Onur'S-AI). While the AI helped set up the core architecture, the fine-tuning, code adjustments, and UI customizations are my own work.

✨ **Features:**
* Audio file (MP3/WAV) and custom album cover uploads
* Lyrics integration
* SQLite local database
* Streamlit-based dark theme interface

🚀 **How to Run:**
1. `pip install streamlit`
2. `python -m streamlit run opp.py`
